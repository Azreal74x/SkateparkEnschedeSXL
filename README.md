# Thanks for checking out my Skatepark Enschede SkaterXL map mod!

I created my own 3D model of Skatepark Enschede and turned it into a playable map for the game Skater XL using Unity. 

# Trailer
https://github.com/user-attachments/assets/d515a856-457c-4404-903f-47e154e5c72a

# How I made it: Key details
-I used Blender and Unity 2019.3.15f1 to turn my 3D skatepark model into a playable Skater XL map. <br>
-SqueegeeDinoToy's Blender plugin to create grind splines for rails, ledges, and other grindable obstacles. <br>
-Billowper's SXL Map Tools in Unity to generate grind colliders and export the map to Skater XL. <br>
-Tested and improved the map across 26 versions until I had a working playable map. <br>
